# 🟢 Level 1 — CSS Basics

## 1. CSS কী?

### 🇧🇩 বাংলা

CSS এর পূর্ণরূপ হলো **Cascading Style Sheets**।

CSS ব্যবহার করা হয় HTML ওয়েবপেজকে সাজানোর জন্য। HTML দিয়ে ওয়েবপেজের structure তৈরি করা হয় এবং CSS দিয়ে সেই structure-এর design করা হয়।

CSS দিয়ে আমরা:

- Text Color
- Font Size
- Background
- Width
- Height
- Spacing
- Border
- Layout
- Animation

ইত্যাদি পরিবর্তন করতে পারি।

### 🇬🇧 English

CSS stands for **Cascading Style Sheets**.

CSS is used to style and design HTML webpages.

With CSS, we can control colors, fonts, spacing, backgrounds, borders, layouts, animations, and more.

### Example

```css
h1 {
  color: blue;
}
